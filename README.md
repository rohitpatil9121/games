# Games

Browser games built on **Projection Lab** (https://rohitpatil9121.github.io/projection_library/), my own
WebGL engine. No three.js, no bundler; plain ES modules.

| Game | Play | What it is |
|---|---|---|
| [TIDEFALL](tidefall/) | [Practice in the browser](https://rohitpatil9121.github.io/games/tidefall/) | Raid the ruins the tide uncovers and race the flood back to camp. 2 to 4 teams, up to 8 players, bots. |

Each game lives in its own folder with its own README. GitHub Pages serves this repository, so every game's
offline Practice mode plays from the link above; online play needs the game's Node server (see its README).
