# Third-party software

Browser code is vendored with pinned versions (no CDN at runtime), and each licence file sits next to the
code. The server has one dependency, installed by `npm install`.

| Name | Version | License | Source | Purpose | Location |
|---|---|---|---|---|---|
| ws | 8.22.0 | MIT | https://github.com/websockets/ws | WebSocket server | `node_modules/ws` (server only) |
| gl-matrix | 3.4.4 | MIT | https://github.com/toji/gl-matrix | Model transforms (quaternions, mat4) | `vendor/gl-matrix@3.4.4/` |
| ZzFX | 1.3.2 | MIT | https://github.com/KilledByAPixel/ZzFX | Procedural sound-effect sample generator | `vendor/zzfx@1.3.2/` |
| Space Grotesk (font) | variable, latin subset | SIL OFL 1.1 | https://github.com/floriankarsten/space-grotesk | Interface text | `vendor/fonts/` |
| JetBrains Mono (font) | variable, latin subset | SIL OFL 1.1 | https://github.com/JetBrains/JetBrainsMono | Numbers and labels | `vendor/fonts/` |

## Engine

`engine/` and `shaders/` are a copy of the Projection Lab engine
(https://github.com/rohitpatil9121/projection_library), itself built on projection_library by Rohit Sawant
(https://github.com/rohit-s-init/projection_library).

`tools/modelkit.mjs` and `tools/chrome.mjs` come from the same author's Night Market and Projection Lab
repositories.

## Art and sound

The trooper model is generated by `tools/make-models.mjs`; weapons, pickups, maps, sky and skyline are built
in code.

Sound effects in `assets/sounds/` are from Kenney's Sci-Fi Sounds, Impact Sounds, Interface Sounds and
Digital Audio packs (https://kenney.nl), CC0 1.0 (`assets/sounds/LICENSE-kenney.txt`). Each one also has a
synthesised ZzFX version in `game/sound.js`, used until the file decodes or if it fails to; the ambient drone
is synthesised.
